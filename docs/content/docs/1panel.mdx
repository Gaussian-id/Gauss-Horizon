---
title: 1Panel availability
description: Chiron Horizon 0.1.2 has no official 1Panel or Docker distribution.
---

Chiron Horizon 0.1.2 does not publish an official Docker image and is not available through the 1Panel app store. The release provides desktop packages for macOS, Windows, and Ubuntu only. macOS uses ad-hoc signing; Windows is unsigned in this first release.

Use the platform package from the [Chiron Horizon GitHub Releases](https://github.com/Gaussian-id/Chiron-Horizon/releases) page. The package includes the desktop application; database agents and JRE 21 components are downloaded from the matching release after installation when they are needed.

Developers who need the Web runtime can build it from this source repository. That source workflow is separate from the 0.1.2 desktop release and is not an official Docker or 1Panel deployment channel.
