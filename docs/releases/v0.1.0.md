# Chiron Horizon 0.1.0

Initial Chiron Horizon release.

## Highlights

- Established the Chiron Horizon identity, profile migration, and refreshed black logo variant.
- Added native ChironDB HTTP connectivity, collection browsing, and ChironQL execution.
- Added a natural-language ChironQL assistant with encrypted credentials, parser validation, human approval for writes, durable history, and consent-scoped result sharing.
- Added sequential manual scripts with per-statement results and approvals, run-local `USE` context, and line-comment shortcuts on macOS, Windows, and Linux.
- Added the offline changelog and build-only desktop CI.

## Distribution notes

- macOS artifacts use ad-hoc signing.
- The Windows installer is unsigned.
- Package-manager publication is deferred.
- Platform build success, native acceptance, signing, and publication are tracked independently.
