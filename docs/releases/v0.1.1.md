# Chiron Horizon 0.1.1

Upstream v0.6.16 synchronization and release hardening.

## Highlights

- Integrated the stable upstream v0.6.16 release while preserving Chiron Horizon branding, ChironDB support, and saved-profile migration compatibility.
- Brought upstream editor, data-grid, export, plugin, metadata, and database-specific fixes into the Horizon release line.
- Kept Chiron Horizon application releases on the `0.1.x` version line independently of upstream tags.

## Release engineering

- Aligned application, Rust crates, Agent packages, JDBC plugin, and documentation versions.
- Hardened release tag/version verification, platform artifact names, checksums, Agent registry generation, managed JRE packaging, and offline driver bundles.
- Continued GitHub Releases as the canonical source for published application and Agent assets.

## Compatibility

Existing Chiron Horizon profiles remain compatible. Database features continue to be exposed according to each driver's implemented backend path and safety policy.
